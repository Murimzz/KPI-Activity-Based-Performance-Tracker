# Frontend — Activity-Based Performance Tracker

React (Vite) client for Contribution / Activity Performance Scores.

## Phase 6

Auth, protected routes, role dashboards, tasks, reviews, and admin screens.

## Run (Windows 11)

```powershell
cd C:\Users\EF\Desktop\AUS\frontend
copy .env.example .env
npm install
npm run dev
```

Ensure backend is running on port **8001** and `.env` contains:

```
VITE_API_BASE_URL=http://127.0.0.1:8001/api
```

Open http://localhost:5173/
